### Project 1 — [Lua Sub-Routines (Coroutines)](./Lua-Sub-Routines/)

| Detail | Description |
|--------|-------------|
| **Title** | Kericho Tea Factory Production Pipeline |
| **Language** | Lua |
| **Topic** | Sub-routines, Coroutines & Cooperative Scheduling |
| **Summary** | Simulates a tea factory's batch processing pipeline using Lua coroutines to demonstrate cooperative multitasking, round-robin scheduling, state persistence, quality control reprocessing loops, and safe error handling. |

### Project 2 — [Names, Bindings and Scopes](./Names-Bindings-and-Scopes/)

| Detail | Description |
|--------|-------------|
| **Title** | Staff Payroll & Allowance Processing Simulator |
| **Language** | C++ |
| **Topic** | Names, Bindings, Scopes, Aliasing, Shadowing & Type Inference |
| **Summary** | A payroll processing system that demonstrates core programming language concepts including static type binding, explicit declarations, variable scope & lifetime, aliasing through reference parameters, variable shadowing, type inference with `auto`, and static local variables. |
